Antora Extensions Registry

Welcome to the Antora ecosystem registry documentation (public site brand: Registry).

This component is published in two places:

  • registry.antora-supplemental.org — the live catalog (extensions and themes)

  • Antora Supplemental docs hub — aggregated alongside other antora-supplemental projects (also on the live site)

Themes are UI bundles (ui.bundle), not Antora playbook extensions. Both are catalogued here.

For site operators installing packages

See Installing from the registry for where each install snippet goes in antora-playbook.yml and how to check that it worked.

For extension authors

See Contributing your Extension for metadata files (antora-registry.md, package.json) and theme submission rules.

For site operators

Repository setup, authentication, and Netlify deployment are documented in the project README, not here.

Features

  • Browse extensions discovered from GitHub topics and registry metadata

  • Deep dependency analysis in the registry view

  • Theme gallery with community submissions (sign-in required)

  • Omni-search on the registry home with category chips (extensions / themes / packages)

Filters

See Registry filters for antora.extensions vs asciidoc.extensions, lifecycle hooks, and Asciidoctor subtypes.
