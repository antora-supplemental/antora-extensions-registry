= Antora Extensions Registry

Welcome to the Antora ecosystem registry documentation (public site brand: *Registry*).

This component is published in two places:

* https://registry.antora-supplemental.org[registry.antora-supplemental.org] — the live catalog (extensions and themes)
* https://docs.antora-supplemental.org/[Antora Supplemental docs hub] — aggregated alongside other antora-supplemental projects (also https://docs.antora-supplemental.org/registry/[on the live site^])

Themes are UI bundles (`ui.bundle`), not Antora playbook extensions. Both are catalogued here.

== For site operators installing packages

See xref:install-guide.adoc[Installing from the registry] for where each install snippet goes in `antora-playbook.yml` and how to check that it worked.

== For extension authors

See xref:contributing.adoc[Contributing your Extension] for metadata files (`antora-registry.md`, `package.json`) and theme submission rules.

== For site operators

Repository setup, authentication, and Netlify deployment are documented in the https://github.com/antora-supplemental/antora-extensions-registry/blob/main/README.adoc[project README], not here.

== Features

* Browse extensions discovered from GitHub topics and registry metadata
* Deep dependency analysis in the registry view
* Theme gallery with community submissions (sign-in required)
* Omni-search on the registry home with category chips (extensions / themes / packages)
